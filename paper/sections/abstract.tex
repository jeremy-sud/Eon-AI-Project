\begin{abstract}
Contemporary Artificial Intelligence predominantly relies on multi-billion parameter deep architectures optimized via backpropagation on high-power GPU clusters, precluding deployment on resource-constrained embedded edge devices ($\le$ 8~KB RAM). In this paper, we present \textbf{Eón}, a mathematically rigorous, neuromorphic Reservoir Computing framework engineered for ultra-low-power microcontrollers within a minimal 1.3~KB RAM and 14~KB Flash footprint. 

We introduce several algorithmic and numerical innovations for constrained edge intelligence: (1) an exact Cholesky decomposition solver ($A = L L^T$) for regularized symmetric positive-definite ridge regression, reducing training complexity from $O(N^3)$ to $O(\frac{1}{3} N^3)$ operations while guaranteeing numerical stability in fixed-point arithmetic; (2) an online Normalized Least-Mean-Squares (NLMS) delta rule enabling continuous on-device adaptation with $O(N)$ complexity and zero covariance matrix storage; (3) an orthogonal reservoir formulation via the Cayley transform ($W = \rho (I - A)(I + A)^{-1}$), ensuring maximum echo state memory capacity; (4) continuous unsupervised synaptic adaptation via Oja's normalized learning rule, which asymptotically bounds weight norms without requiring per-step eigenspectrum evaluations; and (5) a deterministic pseudo-random stream synchronization scheme coupled with a 1-Bit Sign Quantization protocol that compresses model synchronization packets by 8.3$\times$ and reduces wireless time-on-air energy by 2.6$\times$ over LoRa SX1276 links.

We validate Eón across multiple real-world edge benchmarks: cardiac arrhythmia detection with 100\% sensitivity using 1.3~KB RAM on simulated bio-sensors, isolated keyword spotting on ARM Cortex-M4F at 50~$\mu$W inference power, and word-level temporal modeling on chaotic Mackey-Glass series ($MSE \le 0.007$ in Q8.8 fixed-point). Our findings demonstrate that mathematically optimized reservoir dynamics achieve production-grade temporal processing on edge hardware costing under \$3 without cloud dependency.
\end{abstract}
